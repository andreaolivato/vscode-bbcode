# Contributing

Bug reports, new tags and preview fixes are all welcome.

## Setup

```bash
npm install
npm run watch
```

F5 opens an Extension Development Host with the extension loaded and `samples/` open. Edit `samples/demo.bbcode` and watch the preview keep up.

## Checks

```bash
npm run check-types
npm run lint
npm run test:unit     # the engine, in plain Node
npm test              # the above plus integration tests in a real VS Code
```

CI runs all of it on Linux, macOS and Windows. The integration tests need a display, so on Linux they go through `xvfb`.

## Where things live

| Path | What |
| --- | --- |
| `src/bbcode/` | Lexer, parser, resolver, renderer, sanitisers, tag registry. Never imports `vscode`. |
| `src/features/` | Editor integration: completion, hover, diagnostics, folding, symbols, colours, auto-close, editing commands. |
| `src/preview/` | The webview: HTML shell, panel lifecycle, export commands. |
| `media/` | Stylesheet and script that run inside the webview. |
| `syntaxes/` | TextMate grammar, generated by `scripts/generate-grammar.mjs`. |
| `docs/tags.md` | Generated by `npm run docs`. Don't edit it by hand. |

That first row matters. Because `src/bbcode/` has no VS Code dependency, its tests run in milliseconds in a plain Node process instead of booting an editor. Keep new parsing and rendering logic there and keep `vscode` imports out of it.

## Adding a tag

1. Add an entry to `TAG_DEFINITIONS` in `src/bbcode/tags.ts` with a `description`, an `example`, and the `dialects` that have it. Leave `dialects` off if every dialect does.
2. Add a `case` to `Renderer.renderTag`. If the tag takes a value, run it through one of the helpers in `sanitize.ts` first. Never drop a raw value straight into an attribute.
3. Style it in `media/preview.css` using the existing custom properties so it works in every theme.
4. Test it in `src/test/unit/renderer.test.ts`. If the tag accepts a URL, a colour or a size, add a hostile-input case too.
5. `npm run docs` to refresh the reference.

## Regenerating the grammar

`syntaxes/bbcode.tmLanguage.json` is generated:

```bash
node scripts/generate-grammar.mjs
```

Edit the script, not the JSON.

## Security

The renderer is the only thing between a forum post and the webview, so when you touch it: escape all text with `escapeHtml`, run every attribute value through the matching sanitiser, and drop the value when the sanitiser returns `undefined` rather than falling back to the raw one. If you thought of an attack while working on it, add it to the `hostile input` suite.

Found something? Please report it privately. See [SECURITY.md](SECURITY.md).

## Pull requests

Plain commit messages are fine. In the PR, say what changed and how you checked it. If a user would notice the change, add a line under `## [Unreleased]` in `CHANGELOG.md`.

Participation is covered by the [Code of Conduct](CODE_OF_CONDUCT.md).
